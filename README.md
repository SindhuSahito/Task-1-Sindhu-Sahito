# Data Cleaning & Preparation Project

## Description

This project is part of the DecodeLabs Data Analytics Internship.

The objective of this project is to clean and prepare a raw dataset using Python and Pandas. The Students Performance dataset from Kaggle was used to perform data cleaning operations such as handling missing values, removing duplicates, correcting formatting issues, and preparing clean data for analysis.

## Dataset Used

Students Performance in Exams Dataset

Source:
https://www.kaggle.com/datasets/spscientist/students-performance-in-exams

## Technologies Used

* Python
* Pandas
* Google Colab
* GitHub

## Data Cleaning Tasks Performed

* Checked missing/null values
* Removed duplicate records
* Renamed columns for better readability
* Standardized text formatting
* Validated score values
* Exported cleaned dataset


## How to Run the Project

### Step 1

Open the notebook in Google Colab or Jupyter Notebook.

### Step 2

Upload the dataset CSV file.

### Step 3

Run all notebook cells one by one.

### Step 4

The cleaned dataset will be generated automatically.
